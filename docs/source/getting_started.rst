Getting Started
===============

This guide gives the shortest path into the current VmaxBuilder workflow.

Who this is for
---------------

- Researchers integrating transcriptomics and GEM models.
- Developers extending pipeline modules.
- Users who want reproducible Vmax estimation workflows.

What VmaxBuilder does
---------------------

VmaxBuilder organizes processing into orchestrated stages:

1. Model preprocessing.
2. Protein preprocessing.
3. Allocation.
4. Kcat estimation and resolution.
5. Vmax calculation.

Quick path
----------

1. Install the project with :doc:`installation`.
2. Read :doc:`overview` to understand the runtime flow.
3. Run the tutorial in :doc:`tutorial`.
4. Use :doc:`api` for the autogenerated module reference.

Current runtime model
---------------------

- The :class:`~VmaxBuilder.base.orchestrator.Orchestrator` wires the pipeline.
- ``RunConfig`` controls the execution mode.
- ``FullConfig`` holds stage-specific configuration.
- ``Scaffold`` carries inputs, artifacts, outputs, metadata, and diagnostics.
